再編の要点

Monitor は live 専用 running / queued run の活動集約、stream health、key moments だけを担当。completed run の結果サマリは置かない。
Replay は分析ワークスペース Summary / Trace / Compare を同一コンテキストに集約。結果確認から event drill-down まで場所を移動しない。
完了 run の既定着地は Summary `Results` の責務は残すが、見た目は `Replay > Summary` として配置する。

ルーティング

running -> Monitor / Live activity snapshot を主役にして raw event 再生は前面に出さない。
finished -> Replay / Summary まず experiment metrics と viewer diagnostics を見せ、必要ならそのまま Trace に掘る。
compare action -> Replay / Compare 比較表も Replay 側に寄せ、Summary と行き来しやすくする。
